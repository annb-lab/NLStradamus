# NLStradamus

This repo accompanies the research article "NLStradamus: a simple Hidden Markov Model for nuclear localization signal prediction " by Alex N Nguyen Ba, Anastassia Pogoutse, Nicholas Provart, Alan M Moses (2009)

It contains the main perl script (and corresponding version in C++).

A Google Colab notebook is also included to try the most basic use case of NLStradamus.
